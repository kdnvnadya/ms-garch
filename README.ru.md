# Markov-Switching GARCH для моделирования волатильности в кризисные периоды

English version: [README.md](README.md)

Дипломная работа (ВКР): моделирование волатильности финансовых активов в кризисные периоды с помощью Markov-Switching GARCH. В отличие от обычного GARCH, здесь сама волатильность может переключаться между скрытыми режимами ("спокойный" / "кризисный"), и модель находит эти режимы по данным, а не по заранее заданным датам.

## Зачем два актива

Работа проверяет один и тот же метод на двух совсем разных активах. Это не сравнение активов между собой, а проверка метода на прочность:

- **S&P 500** (традиционный фондовый индекс): крах доткомов 2000-2002, финансовый кризис 2008, COVID-19 (март 2020), спад 2022.
- **Bitcoin (BTC-USD)** (намного более волатильный крипто-актив): серия крипто-специфичных крахов: медвежий рынок 2018, COVID-19 (март 2020), крах Terra/Luna (май 2022), крах биржи FTX (ноябрь 2022).

Ряды не привязаны к одному календарному периоду и не сравниваются друг с другом напрямую. По каждому активу берётся максимум доступной истории именно по нему. Если одна и та же модель одинаково чисто разделяет "спокойный" и "кризисный" режимы и на умеренно волатильном индексе, и на гораздо более волатильной криптовалюте, это довод в пользу того, что метод работает не только на одном конкретном ряду данных.

## Дополнительно: тональность новостей и GARCH-X

Обычный GARCH видит только прошлые доходности. Этот блок проверяет, несёт ли новостной фон дополнительную информацию о будущей волатильности (пп. 2.5-2.6 оглавления ВКР).

1. **Модель тональности.** Обучается на Financial PhraseBank (Malo et al., 2014): около 4800 предложений из финансовых новостей с экспертной разметкой negative / neutral / positive. Базовый конвейер: TF-IDF + логистическая регрессия.
2. **Индекс негативности.** Каждый заголовок получает оценку P(negative) − P(positive), из них собирается дневной ряд NEG_t с экспоненциальным затуханием влияния новости.
3. **GARCH-X.** Индекс за вчерашний день добавляется в уравнение дисперсии:

   σ²_t = ω + α·ε²_{t-1} + β·σ²_{t-1} + γ·NEG_{t-1}

   Если γ > 0 и значим, негативный новостной фон повышает волатильность сверх того, что объясняет сам GARCH.

Ограничение: пока используется небольшая вручную собранная панель заголовков вокруг кризисов, поэтому блок показывает метод, а не даёт строгий вывод. В планах: систематический корпус (например, GDELT) и FinBERT вместо TF-IDF.

## Данные

Дневные цены закрытия с Yahoo Finance. CSV уже лежат в репозитории, поэтому ноутбук читает их локально и в сеть не ходит. Если файла нет, он скачивается через `yfinance` один раз и сохраняется в `data/` (автоматическая загрузка заблокирована в части рабочих окружений, поэтому кэш лучше держать в репо). У каждого актива своя максимальная доступная история, не общий период, подробнее выше.

- `data/btc_prices.csv`

## Структура репозитория

Пока один ноутбук, анализ ещё строится. Когда код по каждому блоку стабилизируется, он разойдётся по отдельным модулям и ноутбукам:

```
ms-garch/
├── README.md
├── README.ru.md
├── requirements.txt
├── data/
│   ├── sp500_prices.csv
│   └── btc_prices.csv
├── notebooks/            (план: отдельный ноутбук на каждый блок)
├── src/                  (план: переиспользуемые функции, когда перестанут часто меняться)
└── vkr_msgarch_1.ipynb   (текущий рабочий ноутбук)
```

```bash
pip install -r requirements.txt
```
